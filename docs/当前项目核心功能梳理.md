# 当前项目核心功能梳理

这份文档只描述当前代码里已经存在、已经可用的能力。

它不是路线图，也不是历史 V2 规划稿。

## 1. 当前产品表面

VigilAI 现在有四类入口：

1. 系统首页：`/`
2. 机会系统：
   - `/opportunity/workspace`
   - `/opportunity/activities`
   - `/opportunity/activities/:id`
   - `/opportunity/tracking`
   - `/opportunity/digests`
   - `/opportunity/sources`
   - `/opportunity/analysis/results`
   - `/opportunity/analysis/templates`
3. 选品系统：
   - `/selection/workspace`
   - `/selection/opportunities`
   - `/selection/opportunities/:id`
   - `/selection/compare`
   - `/selection/tracking`
4. 共享 Agent 界面：
   - `/agent`

旧平铺路由如 `/workspace`、`/activities` 仍可访问，但只是跳转到 `/opportunity/*` 下的兼容入口。

## 2. 机会域能力地图

### 2.1 机会工作台

前端页面：

- `app/frontend/src/pages/WorkspacePage.tsx`

正式路由：

- `/opportunity/workspace`

后端接口：

- `GET /api/workspace`

作用：

- 汇总当前机会流状态
- 给用户排优先级
- 展示高价值机会、今日先做、提醒压力、来源告警、日报预览

### 2.2 机会池

前端页面：

- `app/frontend/src/pages/ActivitiesPage.tsx`

正式路由：

- `/opportunity/activities`

后端接口：

- `GET /api/activities`
- `POST /api/activities/ai-filter`

作用：

- 浏览标准化机会列表
- 做固定筛选和排序
- 在固定筛选之后做 AI 精筛
- 发起详情查看和跟进行动

### 2.3 机会详情与动作执行

前端页面：

- `app/frontend/src/pages/ActivityDetailPage.tsx`

正式路由：

- `/opportunity/activities/:id`

后端接口：

- `GET /api/activities/{activity_id}`
- `POST /api/tracking/{activity_id}`
- `PATCH /api/tracking/{activity_id}`
- `DELETE /api/tracking/{activity_id}`
- `POST /api/digests/candidates/{activity_id}`
- `DELETE /api/digests/candidates/{activity_id}`

作用：

- 深看单个机会
- 查看分析状态
- 加入跟进、收藏、补计划、放弃
- 加入或移出日报候选

### 2.4 跟进执行

前端页面：

- `app/frontend/src/pages/TrackingPage.tsx`

正式路由：

- `/opportunity/tracking`

后端接口：

- `GET /api/tracking`
- `POST /api/tracking/{activity_id}`
- `PATCH /api/tracking/{activity_id}`
- `DELETE /api/tracking/{activity_id}`

作用：

- 管理跨机会的执行队列
- 按 stage 和 focus 查看不同跟进状态
- 管理提醒和下一步动作

### 2.5 日报

前端页面：

- `app/frontend/src/pages/DigestsPage.tsx`

正式路由：

- `/opportunity/digests`

后端接口：

- `GET /api/digests`
- `GET /api/digests/candidates`
- `POST /api/digests/candidates/{activity_id}`
- `DELETE /api/digests/candidates/{activity_id}`
- `GET /api/digests/{digest_id}`
- `POST /api/digests/generate`
- `POST /api/digests/{digest_id}/send`

作用：

- 管理日报候选
- 生成日报
- 查看日报详情
- 标记已发送

### 2.6 来源健康

前端页面：

- `app/frontend/src/pages/SourcesPage.tsx`

正式路由：

- `/opportunity/sources`

后端接口：

- `GET /api/sources`
- `POST /api/sources/{source_id}/refresh`
- `POST /api/sources/refresh-all`

作用：

- 查看来源新鲜度和异常状态
- 手动触发刷新

### 2.7 分析管理

前端页面：

- `app/frontend/src/pages/AnalysisResultsPage.tsx`
- `app/frontend/src/pages/AnalysisTemplatesPage.tsx`

正式路由：

- `/opportunity/analysis/results`
- `/opportunity/analysis/templates`

后端接口：

- `GET /api/analysis/results`
- `GET /api/analysis/results/{activity_id}`
- `GET /api/analysis/templates`
- `GET /api/analysis/templates/default`
- `POST /api/analysis/templates`
- `PATCH /api/analysis/templates/{template_id}`
- `DELETE /api/analysis/templates/{template_id}`
- `POST /api/analysis/templates/{template_id}/duplicate`
- `POST /api/analysis/templates/{template_id}/activate`
- `POST /api/analysis/templates/preview`
- `POST /api/analysis/templates/preview/results`
- `POST /api/analysis/run`
- `GET /api/agent-analysis/jobs`
- `POST /api/agent-analysis/jobs`

作用：

- 管理模板化分析策略
- 查看 passed / watch / rejected 结果
- 触发 Agent 分析任务

## 3. 共享 Agent 界面

前端页面：

- `app/frontend/src/pages/AgentWorkspacePage.tsx`

正式路由：

- `/agent`

作用：

- 以 session 为中心发起跨域工作流
- 恢复最近会话
- 查看 artifacts 和 tool 驱动回复

## 4. 选品系统

前端页面：

- `SelectionWorkspacePage`
- `SelectionOpportunitiesPage`
- `SelectionOpportunityDetailPage`
- `SelectionComparePage`
- `SelectionTrackingPage`

作用：

- 研究淘宝和闲鱼候选商品
- 对比机会
- 跟进 shortlisted 商品

## 5. 哪些说法已经不是现状

下面这些说法都已经过时，不应该再被当成当前真相：

- `/workspace` 是正式机会首页
- 当前机会首页还是旧 dashboard
- V2 实施阶段仍然是当前执行口径
- `app/frontend/src/components/workspace/` 是当前真实组件边界

机会工作台的当前实现分析请看：

- `docs/opportunity_workspace_deep_dive.md`
